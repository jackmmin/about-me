### 2026-11-06 · 달력 보기와 통계

- 일기 달력 보기, 날짜별 컨디션(점수·감정 이모티콘), 일기 통계
- 묵상 달력 보기·마음 상태·말씀별 통계
- 건강 달력 보기, 월 달력을 공용 컴포넌트로 분리
- 일기 사진 제한을 장당 10MB·최대 10장으로 확대

### 2026-11-05 · 저장 공간과 성능

- 저장 공간 사용량 표시·80% 경고, 사진 WebP 저장으로 용량 절약
- 새 사진을 Cloudflare R2에 저장, 저장 공간 막대를 사용자별로 나눠 표시
- 데이터 불러오기 속도 개선 (쿼리 축소·캐시·병렬화)
- 기록 제목 100자·본문 20,000자 제한과 글자 수 표시
- 묵상 말씀 책 선택을 검색 가능한 콤보박스로 교체
- 모바일에서 음식·태그 이력 목록이 키패드에 깨지는 문제 수정
- 식후 증상에 소화불량·구토·어지러움·식은땀 추가
- 앱 안 표시 이름을 생활기록으로 변경

### 2026-11-05 · 묵상 탭과 백업

- 묵상 탭 추가: 말씀 여러 개 등록과 절 체크박스 범위 선택
- 간식을 하루 여러 건 기록·수정·삭제
- 홈을 전체 기록의 날짜별 타임라인으로 변경
- 항목별 백업·복원 (저장 위치 선택, 같은 id는 건너뛰기)
- 사진 탭 숨김, 일기 사진 여러 장과 대표 사진(썸네일) 선택
- Android 앱 이름을 생활기록으로 변경
